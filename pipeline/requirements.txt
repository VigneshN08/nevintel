# Hash-pinned dependency lock for the NeviSec pipeline.
#
# The workflow installs with `pip install --require-hashes`, so a compromised
# or re-uploaded package version cannot silently enter the build. This matters
# more than usual here: the build pipeline has write access to what every
# visitor executes, and the May 2026 "Mini Shai-Hulud" compromise pulled CI
# secrets straight out of the GitHub Actions runner's memory.
#
# To change a dependency:
# printf 'feedparser==X\nnh3==Y\nhttpx==Z\n' > requirements.in
# pip-compile --generate-hashes --output-file=requirements.txt requirements.in
# rm requirements.in
#
